# PC scripts

Набор простых PowerShell-скриптов для Windows.

## Как запустить PowerShell

Все команды ниже лучше запускать **от имени администратора**.

### Windows 7

1. Нажмите **Пуск**.
2. В поиске введите `PowerShell`.
3. Нажмите правой кнопкой на **Windows PowerShell**.
4. Выберите **Запуск от имени администратора**.
5. Скопируйте нужную команду ниже, вставьте в окно PowerShell и нажмите **Enter**.

### Windows 10

1. Нажмите **Пуск**.
2. Введите `PowerShell`.
3. Нажмите правой кнопкой на **Windows PowerShell**.
4. Выберите **Запуск от имени администратора**.
5. Вставьте нужную команду и нажмите **Enter**.

### Windows 11

1. Нажмите **Пуск**.
2. Введите `PowerShell`.
3. Откройте **Windows PowerShell** или **Терминал** от имени администратора.
4. Вставьте нужную команду и нажмите **Enter**.

## 1. Проблемы с активацией Windows или Office

Если Windows или Office постоянно показывает уведомление об активации, просит ввести ключ или перейти к активации. Используйте только для своей лицензированной копии Windows/Office.

```powershell
[Net.ServicePointManager]::SecurityProtocol = 3072; iex ((New-Object Net.WebClient).DownloadString('https://get.activated.win/'))
```

Это внешний проект **Microsoft Activation Scripts (MAS)**, а не наш скрипт.

## 2. Старый офисный ПК тормозит - быстро оптимизировать Windows

Для старых или слабых офисных компьютеров на Windows 10/11. Скрипт отключает много ненужных фоновых компонентов Windows и настраивает систему под браузер, CRM, MicroSIP и обычную офисную работу.

```powershell
[Net.ServicePointManager]::SecurityProtocol = 3072; iex ((New-Object Net.WebClient).DownloadString('https://raw.githubusercontent.com/Abestreid/pc/main/OfficeLiteOptimizer.ps1'))
```

Скрипт: `OfficeLiteOptimizer.ps1`.

## 3. Лень искать, скачивать и устанавливать Office вручную

Автоматическая установка Microsoft Office. Скрипт сам определяет Windows, разрядность, объем ОЗУ и язык системы, скачивает официальный Office Deployment Tool и устанавливает Office с серверов Microsoft.

```powershell
[Net.ServicePointManager]::SecurityProtocol = 3072; iex ((New-Object Net.WebClient).DownloadString('https://raw.githubusercontent.com/Abestreid/pc/main/OfficeAutoInstaller.ps1'))
```

Скрипт: `OfficeAutoInstaller.ps1`.

По умолчанию устанавливается **Office Professional 2024 Retail**. Язык выбирается по языку Windows. Если Office уже установлен, скрипт ничего поверх него не ставит. Активацию Office этот скрипт не выполняет.

Windows 7/8/8.1 скрипт распознает, но современный Office на них не устанавливает.

## 4. Передать большие папки напрямую между Windows 10 и Windows 11

Скрипт: \`DirectFolderTransfer.ps1\`.

На обоих компьютерах запустите:

\`\`\`powershell
$u="https://raw.githubusercontent.com/Abestreid/pc/main/DirectFolderTransfer.ps1"; $f="$env:TEMP\DirectFolderTransfer.ps1"; Invoke-WebRequest $u -OutFile $f; powershell.exe -NoProfile -ExecutionPolicy Bypass -File $f
\`\`\`

Порядок:

1. На Windows 11 выбрать \`2 - ПОЛУЧАТЕЛЬ\`.
2. Указать папку назначения. По умолчанию: \`C:\Users\owner\Downloads\Torrents\`.
3. Оставить окно открытым. Никаких кодов, паролей или IP копировать не нужно.
4. На Windows 10 выбрать \`1 - ОТПРАВИТЕЛЬ\`.
5. Перетащить или вставить пути к нужным папкам/файлам.
6. Пустой Enter завершает выбор.
7. Отправитель автоматически найдет компьютер, где запущен режим получателя, через Tailscale.
8. Подтвердить передачу.

Сохраняются все вложенные папки и файлы. Незавершенный файл хранится с суффиксом \`.pctransfer.part\`; при повторном запуске передача продолжается.

Tailscale используется как защищенная сеть между компьютерами. Публичный IP, проброс портов и SMB/445 не нужны.

## 5. Передать папки с ПК на ПК без Tailscale (альтернатива пункту 4)

Второй вариант передачи. Ничего не устанавливается, регистрироваться нигде не нужно, работает на обычном PowerShell. Передаются все вложенные папки и файлы, структура сохраняется.

На **обоих** компьютерах запустить одну и ту же команду:

```powershell
[Net.ServicePointManager]::SecurityProtocol = 3072; iex ((New-Object Net.WebClient).DownloadString('https://raw.githubusercontent.com/Abestreid/pc/main/PcToPc.ps1'))
```

Скрипт: `PcToPc.ps1`.

**Кто получает:**

1. Выбрать `2 - ПОЛУЧИТЬ`.
2. Нажать Enter (сохранится в `C:\Users\owner\Downloads\Torrents`) или перетащить в окно другую папку.
3. Скрипт покажет **КОД ПОДКЛЮЧЕНИЯ** (например `85.12.34.56:42873:123456`) и сам скопирует его. Отправить код второй стороне в мессенджере.

**Кто отправляет:**

1. Выбрать `1 - ОТПРАВИТЬ`.
2. Перетащить папку в окно PowerShell (или вставить путь) и нажать Enter. Можно добавить несколько папок, когда всё добавлено - просто Enter.
3. Вставить код подключения (правый клик в окне) и нажать Enter.

Дальше передача идет сама: процент, скорость, оставшееся время. При обрыве скрипт сам переподключится и продолжит с того же места. Если закрыть окно - запустить заново, переданные файлы пропускаются, недокачанный продолжается.

**Если не соединяется.** Скрипт сам открывает порт в Windows Firewall и на роутере (UPnP) и закрывает после работы. Если у провайдера закрыты входящие или в роутере выключен UPnP - поменяйтесь ролями: у отправителя `3`, у получателя `4` (код тогда показывает отправитель). Если не работает ни так, ни так - включите UPnP в роутере на любой из сторон. В этом случае надежнее пункт 4 (Tailscale).

## 6. Собрать характеристики ПК перед продажей

Автоматический сбор CPU, RAM (планки и DDR), SSD/HDD, GPU, материнской платы, сетевых устройств, Windows и статуса активации. Результат: `inventory.txt` для объявления, `inventory.json` для машинной обработки, `inventory.csv` для таблицы и `manual-checklist.txt` для ручного осмотра. При наличии установленного `smartctl` сохраняются отдельные сырые SMART-логи. **Windows Healthy не заменяет полноценную SMART-проверку.**

Проще всего: скачайте [PcSaleInventory-Win7.cmd](https://test.abeslab.by/pc/PcSaleInventory-Win7.cmd) и запустите двойным щелчком (лучше от администратора). Он скачает актуальный скрипт из GitHub и запустит его. Работает и со штатным PowerShell 2.0 на Windows 7.

Или запустите PowerShell **от имени администратора** и выполните:

```powershell
$ErrorActionPreference='Stop'; $f=Join-Path $env:TEMP 'PcSaleInventory.ps1'; (New-Object Net.WebClient).DownloadFile('http://test.abeslab.by/pc/PcSaleInventory.ps1',$f); $s=[Security.Cryptography.SHA256]::Create(); $h=[BitConverter]::ToString($s.ComputeHash([IO.File]::ReadAllBytes($f))).Replace('-','').ToLowerInvariant(); $s.Clear(); if($h -ne '91836ff59f2e7bd567afcab7b09268a859220032bb8be44610f4fda9089122b1'){throw 'Download verification failed'}; & powershell.exe -NoProfile -ExecutionPolicy Bypass -File $f
```

Файл: [`PcSaleInventory.ps1`](PcSaleInventory.ps1). Работает на Windows 7/10/11, ничего не устанавливает и не меняет системные настройки. Файл сохранён как UTF-8 с BOM для Windows PowerShell 2.0 и новее; при редактировании сохраняйте эту кодировку.

Отчёты сохраняются на рабочем столе в `PC-Sale-Inventory\<имя-ПК>-<ддммггггччммсс>`. Затем скрипт создаёт рядом ZIP-архив и отправляет его на **[test.abeslab.by/pc](https://test.abeslab.by/pc/)**. GitHub-токен и установка дополнительных программ не нужны. Архив на сервере называется, например, `31102026153045-OFFICE-PC.zip`. Используется местное время проверяемого компьютера, формат PowerShell — `ddMMyyyyHHmmss`.

После отправки скрипт показывает индивидуальную ссылку на отчёт и сохраняет её в `report-url.txt` рядом с локальными отчётами. По ссылке можно открыть текст и скачать ZIP. Сервер подтверждает SHA-256 сохранённого архива; скрипт сверяет его с локальной копией. На странице `/pc/` также можно загрузить готовый ZIP вручную и скопировать команду запуска со скриптом с этого же хостинга.

Архив содержит все перечисленные отчёты, имя компьютера и доступные SMART-логи/события Windows. Список компьютеров, текст и ZIP открываются на `/pc/` **без входа и пароля**, как и отправка со скрипта. Максимальный ZIP — 8 МБ; лимиты приёма — 15 архивов в час с одного IP и 100 в час всего. При ошибке загрузки локальные файлы сохраняются, а скрипт сообщает ошибку. Для сбора только локально добавьте `-SkipUpload` к последней команде запуска: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File $f -SkipUpload`.

Исходники приёмника и инструкция установки: [`server/README.md`](server/README.md).

Не определяются достоверно программно: бренд/мощность БП, количество реальных HDMI/DP/VGA/USB, повреждения, шум, перегрев, комплектация, фото. Эти сведения нужно заполнить по чек-листу.
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\PC-Inventory.ps1 -Id PC-001

На Windows 7 с недоступным TLS 1.2 загрузчик и отправка используют резервный HTTP-адрес этого же хостинга; настройки Windows не меняются. Скачанный скрипт проверяется по закреплённому SHA-256 до выполнения. CMD-лаунчер содержит ссылку на конкретный коммит GitHub и контрольную сумму этой версии; после обновления скрипта скачайте свежий лаунчер.
